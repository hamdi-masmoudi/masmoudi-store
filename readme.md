# Masmoudi Store

Mini-projet Dev. Web côté client 

## Thème

Site vitrine d'une boutique en ligne de vêtements pour homme avec commande simulée.

## Technologies

* HTML5 (balises sémantiques : header, nav, main, section, article, footer)
* CSS3 (fichier externe, variables, Flexbox, Grid, media queries, mobile-first)
* JavaScript (fichiers externes, manipulation du DOM, événements, validation de formulaires)

## Pages

* `index.html` : boutique (catalogue de produits cliquables)
* `pages/produit.html` : page du produit choisi  avec formulaire de commande
* `pages/contact.html` : formulaire de contact

## Interactions JavaScript

1. Menu burger (mobile)
2. Affichage du produit choisi, selon l'id dans l'adresse de la page
3. Calcul du total de la commande selon la quantité
4. Validation du formulaire de commande (nom, téléphone, adresse, quantité)
5. Compteur de caractères et validation du formulaire de contact

La commande est simulée : aucune donnée n'est envoyée à un serveur.

## Arborescence


index.html
pages/    produit.html, contact.html
css/      style.css
js/       produits.js (catalogue), script.js (interactions)
